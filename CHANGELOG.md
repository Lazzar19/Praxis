# Changelog

## 0.1.0

Experimental pre-release. The shipping path is the always-on rule and the hooks. The MCP server, the question card, and the YAML session stay only as the legacy test path.

Praxis can block project edits while a learning decision is open.

Confirmed decisions are listed in `.praxis/timeline.md`, in the order they were written. Ask to see the timeline and that file opens beside the chat.

`/start-praxis` turns Praxis on after it was left off. The session then names the goal and the architecture already in the tree before asking for their sentence.
