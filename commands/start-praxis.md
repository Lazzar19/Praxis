---

Turn Praxis on for this project. Write `.praxis/progress.md` with exactly these lines:

```text
Praxis: on
Status: pending
Topic: their sentence
Bypass: none
```

The hook allows that write and clears the off flag. Then read the project before any option list. The goal is the README heading or the package description. The architecture already in the tree is data access, an API boundary, deployment, a framework, or an entry point. Restate that in a short brief. That brief is not their sentence and not their choice. Ask only for their sentence. Do not offer a stack, a database, or a deployment yet.
